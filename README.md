Blinkit Sales Analytics Dashboard

Project Overview

An interactive sales analytics dashboard created in Microsoft Excel to explore Blinkit grocery sales data. The dashboard presents key performance indicators (KPIs) and visual insights into sales across product categories and outlet characteristics.

Objectives

* Summarize overall sales performance using KPI cards.
* Compare sales across item types.
* Analyze sales by fat content.
* Explore sales by outlet location type.
* Examine sales trends by outlet establishment year.
* Enable interactive filtering using an Outlet Location Type slicer.

Tools Used

* Microsoft Excel
* PivotTables and PivotCharts
* Excel formulas
* Interactive slicers
* Data visualization and dashboard design

Key Dashboard Features

* Total Sales
* Average Sales
* Number of Items
* Average Rating
* Sales by Item Type
* Sales by Fat Content
* Sales by Outlet Location
* Sales by Outlet Establishment Year

Skills Demonstrated

* Data analysis
* Data summarization
* PivotTable creation
* KPI reporting
* Interactive dashboard development
* Data visualization

How to Use

1. Download the Excel workbook from this repository.
2. Open it in Microsoft Excel.
3. Navigate to the Dashboard worksheet.
4. Use the Outlet Location Type slicer to filter the dashboard, where supported.
